# Prophets: library sections (Isaiah, Lamentations, Baruch, Ezekiel, Hosea, Joel, Amos, Obadiah, Micah, Nahum, Habakkuk, Zephaniah, Haggai, Zechariah, Malachi)

**Status: approved by the owner on 2026-11-12** (the owner approved the section binnings of every group in advance; this record lists them so any can still be changed).

Titles are written for this site and never quote scripture. Ranges use the plan's (Hebrew-based) numbering and fall on chapter boundaries except where a book's own divisions fall mid-chapter. A build confirmed every verse of each book is covered exactly once; reading times use 230 words per minute. Outlines from `pnpm library:propose` are alongside. Jeremiah, Daniel and Jonah are on the path.
