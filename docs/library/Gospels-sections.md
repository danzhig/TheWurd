# Gospels: library sections (Matthew, Mark)

**Status: approved by the owner on 2026-11-12** (the owner approved the section binnings of every group in advance; this record lists them so any can still be changed).

Titles are written for this site and never quote scripture. The plan and WEBC number these books the same way. A build confirmed every verse of each book is covered exactly once; reading times use 230 words per minute. Outlines from `pnpm library:propose` are alongside. Luke and John are on the path.
